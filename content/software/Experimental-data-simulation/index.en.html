  Purposes

This open-source, R-based web application is suitable for teaching and research in the experimental and quantitative sciences. It creates varied data sets with specified structures, such as between-group and within-participant variables that can be categorical or continuous. The parameters are set in the tabs (sections) of the top menu, and the data set can be downloaded from the last tab. The application saves time and offers flexible control over the parameters.

Guidelines

General guidelines include the following:

  • In the names of variables, it is best to use only alphanumeric characters and underscores, which can separate words (e.g., variable_name). Each variable needs a different name.

  • In the levels of categorical variables, alphanumeric characters, special characters and spaces are allowed.

  • In numeric fields (e.g., ‘Mean’, ‘Standard deviation’, ‘Relative probability [0, 1]’), only numbers and decimal points are allowed.

  • As the data set grows, so does the processing time.

More specific guidelines are available in each section.

Code

This web application was developed in R (R Core Team, 2020). The code is available on GitHub, where contributions are welcome. A copy is archived on Zenodo (Bernabeu & Lynott, 2024). The initial code drew on Section 5.7 (Simulating data for multi-factor designs) of Crump (2017). The R packages used include dplyr (Wickham et al., 2020), DT (Xie et al., 2020), flexdashboard (Iannone et al., 2020), shiny (Chang et al., 2020) and stringr (Wickham, 2019).
